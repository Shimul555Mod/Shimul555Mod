ব্যবহার বিধি

  1. প্রথমে HTML <head> এর মধ্যে preload লিঙ্ক যুক্ত করুন।
  2. তারপর CSS এ @font-face কোড যুক্ত করুন।
  3. পরবর্তীতে CSS variable এবং global font family প্রয়োগ করুন।
  4. এখন যেকোনো টেক্সট এলিমেন্টে স্বয়ংক্রিয়ভাবে ফন্ট প্রযোজ্য হবে।
  5. যদি কোনো সমস্যা হয়, ব্রাউজার ক্যাশ ক্লিয়ার করুন বা Ctrl+F5 চাপুন।
