ব্যবহার বিধি

  1. প্রথমে আপনার পছন্দের ফন্টের কার্ড থেকে `@font-face` কোডটি কপি করুন এবং আপনার CSS ফাইলে যুক্ত করুন।
  2. এরপর CSS `body` বা নির্দিষ্ট কোনো এলিমেন্টের জন্য `font-family` কোডটি কপি করে ব্যবহার করুন।
  3. (ঐচ্ছিক) ওয়েবসাইটের পারফরম্যান্স ভালো করার জন্য HTML `` ট্যাগের মধ্যে ফন্টের `` কোড যুক্ত করতে পারেন।
  4. ব্রাউজার ক্যাশজনিত সমস্যা এড়াতে প্রয়োজনে ক্যাশ ক্লিয়ার করুন।
  5. নতুন ফন্ট কার্ড যুক্ত করতে, HTML ফাইলের টেমপ্লেটটি ব্যবহার করুন।
