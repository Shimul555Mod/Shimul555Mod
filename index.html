ব্যবহার বিধি

  1. HTML <head> এর মধ্যে ফন্ট প্রিলোড লিঙ্ক যুক্ত করুন।
  2. CSS এ @font-face কোড যুক্ত করুন।
  3. CSS variable বা সরাসরি font-family প্রয়োগ করুন।
  4. ওয়েবসাইটের টেক্সটে ফন্ট স্বয়ংক্রিয়ভাবে প্রয়োগ হবে।
  5. ব্রাউজার ক্যাশ ক্লিয়ার করতে হতে পারে সমস্যা হলে।
  6. নতুন কার্ড যোগ করতে .cards-container এর মধ্যে HTML স্ট্রাকচার কপি করে যুক্ত করুন।
